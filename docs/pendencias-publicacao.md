## Outside the command's reach

The validator warns that it runs only a subset of the directory's checks. Left unchecked:

- Security scan and policy review, done by the directory on submission.
- Additional portal rules: a clean local validation does not guarantee a clean validation there.
- Which `wh` components (`UserPromptSubmit` hook, agents, `!cat` injection in the skills) load in claude.ai and in Cowork: see the per-app support table at `claude.com/docs/plugins/platform-support`.

CI (`.github/workflows/ci.yml`) now runs both `claude plugin validate --strict` commands (installs the CLI via `npm`; the command does not require login). The step has not run on GitHub yet: check the first run after the push.
